# Além do Padrão — Desafiando a Hegemonia nas Práticas Corporais

Site oficial da exposição **“Além do Padrão: Desafiando a Hegemonia nas Práticas Corporais”**, vinculada ao projeto de extensão **“Construindo um Observatório de Práticas Corporais: interpretações e sínteses a partir da cultura corporal comunitária”**, do IFSP — Campus São Paulo.

## 🌐 Site

**[Acessar a exposição — Além do Padrão](https://isabellabartu.github.io/napne_exposicao/)**

## Sobre a exposição

A exposição propõe uma reflexão sobre os padrões corporais hegemônicos presentes na sociedade e na cultura, apresentando diferentes corpos e formas de participação nas práticas corporais.

Por meio de registros fotográficos e textos de apoio, a exposição aborda a presença de diferentes corporeidades em esportes, danças, lutas, ginásticas e outras práticas corporais, buscando ampliar a compreensão sobre diversidade, participação, acessibilidade e ocupação dos espaços.

A pergunta que orienta a exposição é:

> **Quem define o que um corpo pode fazer?**

## Painéis

A exposição está organizada em quatro painéis:

1. **Espaços para todos**
2. **Práticas que aproximam**
3. **Corpos em Movimento**
4. **Quem pode ocupar um corpo?**

Cada painel possui uma página própria com a imagem correspondente e recursos de acessibilidade.

## ♿ Acessibilidade

O site foi desenvolvido considerando diferentes necessidades de acesso e navegação. Entre os recursos disponíveis estão:

- ajuste do tamanho do texto;
- controle de espaçamento entre linhas;
- controle de espaçamento entre letras;
- opções de contraste;
- opção de sublinhar links;
- redução de animações;
- navegação por teclado;
- foco visual nos elementos interativos;
- recurso de “Pular para o conteúdo”;
- textos alternativos para imagens;
- audiodescrição;
- reprodução da audiodescrição por síntese de voz;
- integração com VLibras nas páginas dos painéis.

As preferências de acessibilidade podem ser mantidas entre as páginas por meio do `localStorage`.

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- JavaScript puro
- CSS Grid e Flexbox
- Web Speech API (`SpeechSynthesis`)
- `localStorage`
- VLibras

Não é necessário backend ou banco de dados.

## 📱 Responsividade

O site foi estruturado para diferentes tamanhos de tela, incluindo:

- computadores;
- tablets;
- smartphones.

A interface utiliza CSS responsivo para adaptar textos, imagens, cards, navegação e controles de acessibilidade.

## 🔊 Audiodescrição

As páginas dos painéis disponibilizam a audiodescrição em texto e também permitem sua reprodução por síntese de voz do navegador.

O áudio não é iniciado automaticamente.

## 🤟 VLibras

As páginas dos painéis contam com integração ao VLibras como recurso complementar de acessibilidade.
